تثبيت WALOW BLUEPRINT على شاشة الهاتف
=====================================
1) ارفع كل ملفات هذا المجلد (index.html, sw.js, manifest.webmanifest, icon-*.png) إلى استضافة مجانية بـ HTTPS:
   - Netlify: افتح app.netlify.com/drop واسحب المجلد كاملاً → يعطيك رابطاً.
   - أو GitHub Pages / Cloudflare Pages.
2) افتح الرابط في Chrome على الهاتف.
3) قائمة ⋮ → «تثبيت التطبيق» (أو «إضافة إلى الشاشة الرئيسية»). أو اضغط زر 📲 داخل التطبيق.
4) بعد أول فتح بالإنترنت يعمل التطبيق (والنماذج الجاهزة) بدون إنترنت. مفتاح Gemini يبقى محفوظاً على جهازك.
